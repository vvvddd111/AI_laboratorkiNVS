Для данной работы используется датасет Ames Housing Dataset. Целевая переменная – цена на дом в зависимости от параметров. 

Первым шагом происходит считывание данных из датасета, затем через fillna заполняются медианными данными значения NaN.
Затем происходит перевод текстовых признаков в категоральные через get_dummies. Затем данные разделяются на признаки X (с удалением ненужных столбцов) и целевую пересенную y.
Даные разделяются на тестовые и тренировочные и масштабируются.
Затем строится матрица корреляций, отображающая корреляцию между признаками. Она позволяет найти признаки, которые могут быть  связаны между собой.

После этого определяются веса признаков. Определяются оптимальные парамеры и поисходит тестирование весов в нескольких метриках: OLS, Ridge, Lasso (в двух вариантах) и ElasticNet.

Затем строится график, показывающий разницу в весах, присвоенных признакам разными алгоритмами. Наиболее весомыи признаками из отображённых на графике оказались год постройки и общее состояние. При этом Lasso с высоким показателем alpha (5000) не присваивал знчимость почти никаким признакам: из отображённых на графике признаков значимость по Lasso5000 была только у года постройки.
