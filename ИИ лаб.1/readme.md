Credit Risk Dataset - датасет, позволяющий связать риск просрочки клиентом выплат по кредиту с различными показателями (возраст, доход, размер кредита и т.д.).

Необходимо составить модель, способную предсказывать, к какой категории может относиться кредит: к просроченным или выплаченным в срок. Для этого производится получение данных из датасета, визуализация для определения корреляции между определёнными показателями, а затем данные подготавливаются для обучения модели: нечисловые данные переводятся в логический вид, а числовые приводятся к единой размерности. Затем проводится оценка точности прогнозов получившейся модели.

Работа состоит из следующих этапов:
• импорт библиотек для возможности использования необходимого функционала
• получение информации о размерности датасета и вывод сгруппированных данных
• построение графика для определения зависимости между выбранными показателями
• выделение категоральных признаков и представление их в логическом виде
• масштабирование числовых признаков для приведения их к единой размерности
• обучение модели на тренировочных данных и оценка её точности

В конечном счёте модель продемонстрировала высокий показатель accuracy (92.13%), что означает, что её прогнозы в основном совпадали с имеющимися в датасете данными.
